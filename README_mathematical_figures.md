# 🎨 Генератор сложных математических фигур

Этот проект содержит код на Python для создания и визуализации различных сложных математических фигур и фракталов.

## 📋 Включенные фигуры

1. **Спираль Фибоначчи** - красивая спираль, основанная на числах Фибоначчи
2. **Фрактал Мандельброта** - знаменитый фрактал на комплексной плоскости
3. **Кривая Лиссажу** - параметрические кривые с гармоническими колебаниями
4. **Полярная роза** - красивые узоры в полярных координатах
5. **Аттрактор Лоренца** - хаотическая система в 3D пространстве
6. **Треугольник Серпинского** - рекурсивный фрактал
7. **Кривая дракона** - самоподобная кривая
8. **Параметрическая поверхность** - сложная 3D поверхность

## 🚀 Установка

1. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

2. Или установите вручную:
```bash
pip install numpy matplotlib
```

## 💻 Использование

### Интерактивный режим
Запустите основной скрипт для интерактивного выбора фигур:
```bash
python mathematical_figures.py
```

### Демонстрация всех фигур
Для автоматического показа всех фигур:
```bash
python run_figures.py
```

### Использование как модуль
```python
from mathematical_figures import MathematicalFigures

# Создаем объект
math_fig = MathematicalFigures()

# Рисуем конкретную фигуру
math_fig.fibonacci_spiral()
math_fig.mandelbrot_set()
math_fig.lorenz_attractor()
```

## 🎛️ Настройка параметров

Многие фигуры можно настроить с помощью параметров:

```python
# Спираль Фибоначчи с 10 квадратами
math_fig.fibonacci_spiral(n_squares=10)

# Фрактал Мандельброта высокого разрешения
math_fig.mandelbrot_set(width=1200, height=900, max_iter=150)

# Кривая Лиссажу с разными параметрами
math_fig.lissajous_curve(a=5, b=7, delta=0.5)

# Треугольник Серпинского большей глубины
math_fig.sierpinski_triangle(depth=8)
```

## 🎨 Особенности

- **Темная тема**: Все графики используют темную тему для лучшего восприятия
- **Градиентные цвета**: Многие фигуры используют цветовые градиенты
- **3D визуализация**: Поддержка трехмерных фигур
- **Интерактивность**: Возможность вращения и масштабирования 3D фигур
- **Высокое качество**: Настроенные параметры для красивого отображения

## 📐 Математические основы

- **Спираль Фибоначчи**: Основана на последовательности Фибоначчи и золотом сечении
- **Фрактал Мандельброта**: Множество точек c, для которых z(n+1) = z(n)² + c не расходится
- **Аттрактор Лоренца**: Система дифференциальных уравнений, демонстрирующая хаотическое поведение
- **Треугольник Серпинского**: Рекурсивный фрактал с самоподобной структурой

3. В некоторых средах может потребоваться установка GUI backend для matplotlib

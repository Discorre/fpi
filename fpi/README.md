# Программа для рисования сложных математических фигур

Эта программа на Python создает красивые визуализации различных сложных математических фигур и концепций.

## Возможности

1. **Фракталы**
   - Множество Мандельброта
   - Множество Жюлиа

2. **Параметрические кривые**
   - Роза (полярные кривые)
   - Лемниската Бернулли
   - Гипоциклоида
   - Эпициклоида

3. **Спирали**
   - Архимедова спираль
   - Логарифмическая спираль
   - Спираль Ферма
   - Гиперболическая спираль

4. **3D поверхности**
   - Седловые поверхности
   - Параболоиды
   - Волновые поверхности
   - Тор
   - Деформированные сферы
   - Проекция бутылки Клейна

5. **Специальные визуализации**
   - Эпициклы Фурье
   - Аттрактор Лоренца

## Установка

1. Создайте виртуальное окружение:
```bash
python3 -m venv math_env
source math_env/bin/activate
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

### Полная демонстрация всех фигур:
```bash
python mathematical_figures.py
```

### Простое демо:
```bash
python simple_demo.py
```

### Использование в коде:
```python
from mathematical_figures import MathematicalFigures

figures = MathematicalFigures()

# Нарисовать множество Мандельброта
figures.mandelbrot_set()

# Нарисовать спирали
figures.spirals()

# Нарисовать 3D поверхности
figures.complex_3d_surfaces()
```

## Примеры фигур

Программа создает высококачественные математические визуализации, включая:

- **Фракталы** - самоподобные структуры с бесконечной детализацией
- **Параметрические кривые** - элегантные кривые, определяемые параметрическими уравнениями
- **Спирали** - различные типы спиральных кривых
- **3D поверхности** - трехмерные математические поверхности
- **Хаотические системы** - визуализация странных аттракторов

Все графики имеют подписи на русском языке и профессиональное оформление.
